# Flat Competition Chess Set

A neutral modern Staunton set designed for clear play on desktop and mobile chessboards.

## Design

* Flat two dimensional silhouettes
* Clean geometric curves
* Consistent bases and square safe proportions
* Solid white and solid near black pieces
* Transparent negative space for internal details
* No gradients, textures, shadows, or brand specific artwork

## Files

The twelve transparent PNG sprites use the Khon's Chess naming convention:

* `white-k.png`
* `white-q.png`
* `white-b.png`
* `white-n.png`
* `white-r.png`
* `white-p.png`
* `black-k.png`
* `black-q.png`
* `black-b.png`
* `black-n.png`
* `black-r.png`
* `black-p.png`

Place the folder inside `pieces/competition-flat/` and register the theme in the selector and theme loading logic.
